# N Leela Venkata Prasad — Portfolio

A fast, responsive portfolio centered on verified product work by [N Leela Venkata Prasad](https://github.com/lvprasad-dev), a full-stack developer in Vijayawada, India.

## Featured work

- [KabaddiArena](https://github.com/lvprasad-dev/KabaddiArena) — local kabaddi operations, scoring, tournaments, profiles, and communication.
- [UNIVA Ticketing](https://github.com/lvprasad-dev/univa-ticketing-platform) — event discovery and ticket booking with OTP authentication.
- [Salon Queue](https://github.com/lvprasad-dev/salon-queue) — real-time salon queue management and customer booking.

## Portfolio stack

The site deliberately uses semantic HTML, modern CSS, and a small amount of JavaScript. It has no runtime framework or package dependency, keeps interaction progressive, supports reduced motion, and is designed for keyboard and mobile use.

## Run locally

Open `index.html` directly, or serve the folder with any static HTTP server.

## Content policy

Portfolio claims are based on public GitHub repositories and live project links. The site does not invent employers, clients, experience length, awards, testimonials, or impact metrics.
